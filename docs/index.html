The Evolution of JD-GUI

Original JD-GUI

v1.6.6
  • Excellent `.class` file decompilation
  • Syntax highlighting
  • Standalone graphical utility
  • Basic, case-insensitive string search
  • Search results cluttered with substring false-positives
  • Unable to filter search by specific file types or paths
  • Loses search history upon restarting

Enhanced Edition

v2.0.0
  • Everything in Original, plus:
  • Advanced Multi-File Search: Simultaneously query `.class` and resource files
  • Exact & Regex Match: Harness full Regular Expressions and pinpoint Exact Matches
  • File Mask Scoping: Filter results instantly using powerful glob patterns (e.g., `*.xml`)
  • Persistent History: Automatically remembers your patterns and masks across restarts
  • UX Fixes: Resolved tree-collapsing and highlighter reset bugs during search

About the Application

What is JD-GUI?

JD-GUI is a standalone graphical utility that displays Java source codes from compiled .class files. It allows you to browse the reconstructed source code for instant access to methods and fields. It is an invaluable tool for developers who need to recover lost source code, explore Java runtime libraries, or analyze proprietary libraries.

Powered by JD-Core

Under the hood, JD-GUI uses the JD-Core library, which reconstructs Java source code from one or more compiled .class files. JD-Core natively supports new features from modern Java versions, such as annotations, generics, and enum types.
